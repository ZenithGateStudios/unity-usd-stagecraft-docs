Documentation

USD Stagecraft 1.0.0

Load OpenUSD (.usd / .usda / .usdc / .usdz) files at runtime in Unity, preview them in the Editor without Play mode, and iterate with manual reload from the USD Stage panel.

Supported environments

Unity2022.3 LTS or later
macOSApple Silicon (arm64) only
Windowsx64
Render pipelinesBuilt-in RP, URP, and HDRP (optional HDRP host)

Installation

Get USD Stagecraft on the Unity Asset Store (v1.0.0 — Windows x64 and macOS Apple Silicon).

  1. Open Window > Package Manager in Unity.
  2. Set the package source to My Assets.
  3. Select USD Stagecraft, then download and import it.
  4. Confirm the package appears under Packages/com.zenithgatestudios.usd-stagecraft/.

Optional samples can be imported from the Package Manager samples section.

Quick start: Editor preview

  1. Add an empty GameObject or use the Stage Preview sample scene.
  2. Add the UsdStagePreview component.
  3. Set File Path to a valid USD file.
  4. The USD hierarchy appears under the GameObject in the Scene view without entering Play mode.

Changing File Path, Shader Name, or Scale reloads the preview in the Editor.

Quick start: Runtime loading

Place runtime USD files under Assets/StreamingAssets/, then load them with UsdLoader.LoadAsync.

using UsdStagecraft;
using UnityEngine;

public class LoadUsdOnce : MonoBehaviour
{
    private LoadResult result;

    private async void Start()
    {
        result = await UsdLoader.LoadAsync("/absolute/path/to/scene.usda", "Standard", 0f);
        if (!result.IsSuccess)
        {
            Debug.LogError(result.ErrorMessage);
            return;
        }

        result.Root.transform.SetParent(transform, false);
    }

    private void OnDestroy()
    {
        if (result != null && result.IsSuccess)
        {
            UsdLoader.Unload(result);
        }
    }
}

Core workflows

Stage preview

Edit mode uses synchronous loading for preview. Play mode uses asynchronous loading through Load() or Auto Load On Start. Multiple UsdStagePreview instances per scene are supported.

USD Stage window

Open via Window > USD Stagecraft > USD Stage. Toolbar File / Actions / Options, Prim tree + properties, Layers / EditTarget, animation transport, and Bake / Write-back.

Full USD Stage window guide in README.md

Manual reload

Automatic file watching is disabled in v1.0.0. After saving USD in your DCC, click Reload (diff) or Shift+click / Reload Full in the USD Stage toolbar.

UsdSkel + Bake

Skeletal stages preview with SkinnedMeshRenderer. Bake to Prefab emits AnimationClip, skinned prefabs, and optional StageTimeline.playable.

Variants and edit layers

Inspector and USD Stage panel expose variants, EditTarget layers, and Transform / Visibility write-back without overwriting the original root USD as the primary workflow.

Known limitations

  • macOS Apple Silicon (arm64) and Windows x64.
  • Very large USD files may load slowly or stress memory.
  • USD variants and payloads are partially supported.
  • UsdSkel: linear blend skinning only, up to 4 joint influences per vertex.
  • UsdGeomBasisCurves is not supported (planned for v1.1).
  • HDRP is integrated but not every DCC / USD combination is fully validated.
  • Writing keyframes back to USD timeSamples is planned for v1.1.

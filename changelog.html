USD Stagecraft Changelog

All notable changes to USD Stagecraft are documented here.

1.0.0 2026-07-09

Added

  • UsdSkel runtime preview — Bone hierarchy + SkinnedMeshRenderer, time-sampled joint evaluation via UsdAnimationPlayer (LBS, up to 4 influences).
  • Skeleton + Xform AnimationClip bake — Joint and transform curves + AnimatorController during Bake to Prefab / Import.
  • SkinnedMesh Prefab promotion + relink — Visuals/Skinned_*/ prefab output and stage hierarchy relink.
  • Timeline / Playable integration — Preview time driver and baked StageTimeline.playable.
  • UsdScriptedImporter skeletal mesh + clip support — Animated USD import with clips, skinned prefabs, and timeline.
  • DiffReload skinning — Deferred skinning pass after reload.
  • Multi-stage preview — Multiple UsdStagePreview instances per scene.
  • com.unity.timeline dependency — Optional UsdStagecraft.Timeline assembly.

Deferred to v1.1

  • UsdGeomBasisCurves — hair, grass, cables, etc.

Notes

  • v1.0 formal release on main / package 1.0.0.

0.4.0

Added

  • instanceable / PointInstancer — Instance proxies and PointInstancer mesh expansion (GPU instancing not yet supported).
  • HDRP (optional UsdStagecraft.Hdrp) — HDRenderPipelineHost for materials, lights, and DomeLight via GradientSky.
  • USD Stage panel — property editing — Transform ops, purpose, kind, and references viewer.

Changed

  • Editor assembly precompiled as UsdStagecraft.Editor.dll for distribution packages.

Removed

  • macOS Intel (x86_64) support — macOS plugins are Apple Silicon (arm64) only.

0.3.0

Added

  • UsdGeomSubset (materialBind) — Sub-mesh splitting and multiple UsdPreviewSurface assignments.
  • UsdLux extensions — DomeLight environment approximation, RectLight size, spot shaping, intensity / exposure / color.
  • .usdz — Local file paths accepted by the loader.

0.2.0

Added

  • Windows (x86_64) native plugins — Editor and Standalone Windows x64.
  • Third-party OSS attribution and full Apache 2.0 license text in ThirdParty/README.txt.

Notes

  • When upgrading the OpenUSD SDK, refresh third-party notices and version strings as applicable.

0.1.2 2026-05-08

Added

  • ThirdParty/README.txt: attribution, NOTICE, and full Apache 2.0 text for redistributed OpenUSD 0.26.5, Intel oneTBB, plus MaterialX / usdMtlx notice.

0.1.1 2026-04-29

  • Minor bug fixes.
  • Minor update.

0.1.0 Early Access 2026-04-29

Added

  • Runtime loading of OpenUSD .usd, .usda, and .usdc files.
  • UsdLoader async and sync USD file loading API.
  • UsdMeshBuilder mesh conversion, UsdMaterialLoader material support, and UsdTextureCache texture caching.
  • UsdStagePreview Editor preview mode.
  • macOS Apple Silicon arm64 native plugin.

Known limitations

  • macOS Apple Silicon only at release time.
  • USD variants and payloads are partially supported.
